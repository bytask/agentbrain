# agentbrain を作る

agentbrain は、ある人の仕事を AI が進めるための文脈を置くフォルダ。中身は 6 種類に分かれる。

| 箱 | フォルダ | 中身 |
|---|---|---|
| 地図 | `CLAUDE.md` | どこに何があるか、どう動くか |
| 事実 | `10-自分/` `50-知識/` | 本人・関係者・言葉についての本当のこと |
| 手順 | `20-業務/` | 担当業務の一覧と、業務ごとの概要・手順 |
| 今 | `30-進行中/` | 今週の優先事項と動いている案件 |
| 記録 | `40-記録/` | 決定ログ、学び、会議 |
| 受け皿と成果物 | `00-受け皿/` `90-成果物/` | 未整理のものと、AI が作ったもの |

雛形はこのスキルのベースディレクトリにある `template/`（同じ内容をこのファイルの末尾にも載せている）。各ファイルの `>` で始まる行が、利用者に聞く質問になっている。

## 進め方の原則

- **聞いたらすぐ書く。** 1 つ答えをもらうたびに、該当ファイルへ書き込む。最後にまとめて書かない（途中で会話が切れても残るようにする）。
- **推測で埋めない。** 答えが無い項目は「（未記入）」のまま残す。会話や資料から読み取れたことを書くときは、書く前に本人に確かめる。
- **一度に聞くのは 1〜3 問。** 選択肢を示せる質問は、質問ツールがあればそれを使う。
- **本人の言葉で書く。** 言い換えて立派にしない。箇条書きで短く書く。
- **秘密は書かない。** パスワードや認証コードを答えられても書かず、「場所だけ書きます」と伝える。
- **既存ファイルを上書きしない。** 同じ名前のファイルがあれば、中身を見せてどうするか聞く。

## 1. 状態を確かめる

作業フォルダを見て、次のどれかを判断する。

| 状態 | 次にやること |
|---|---|
| agentbrain がまだ無い | 手順 2 へ |
| agentbrain がある（`CLAUDE.md` の見出しが `# agentbrain`） | 「（未記入）」が残るファイルを数えて報告し、手順 3 の続きから再開する |
| 「業務を追加して」と言われた | 手順 4 へ |

作業フォルダが選ばれていない、または書き込めないときは、フォルダを選んでもらってから始める。

## 2. 雛形を置く

1. 置き場所を聞く。既定は、作業フォルダの直下に `agentbrain` という名前のフォルダを作る。作業フォルダ自体が空で、そこを agentbrain にしたい場合は直下に置く。
2. `template/` の中身を、フォルダ構成を保ったまま置き場所へ写す。シェルが使えるなら丸ごとコピーする。`template/` を読めない、またはコピーできないときは、このファイルの末尾にある「雛形の中身」を、見出しのパスどおりに 1 ファイルずつそのまま書き出す。どちらの方法でも中身は同じになる。
3. 空のフォルダを 2 つ作る: `00-受け皿/取り込み/` と `90-成果物/`。
4. 利用者の名前を聞き、`CLAUDE.md` の `{{名前}}` をすべて置き換える。
5. できたフォルダの 6 つの箱を、上の表の言葉で 3〜4 行で説明する。長い説明はしない。

## 3. インタビュー（1 回目は 10〜15 分で終える）

次の順に進める。各ファイルを開き、`>` の質問を上から聞く。答えを書いたら、その質問の行と「（未記入）」を消す。

1. `10-自分/プロフィール.md` — 全項目
2. `20-業務/業務一覧.md` — 業務を挙げてもらい、表に 1 行ずつ足す。5 件前後で止めてよい
3. `30-進行中/今週.md` — 全項目。更新日に今日の日付を入れる

ここで一度区切り、続けるか聞く。続ける場合は手順 4 へ。`判断基準.md` `文体.md` `50-知識/` は初回に無理に埋めず、仕事の中で出てきたときに足す。

資料を持っている人には、質問に答える代わりに `00-受け皿/取り込み/` へ入れてもらう。入れられた資料を読み、読み取れた内容を「こう書いてよいですか」と確かめてから該当ファイルへ書く。

## 4. 業務を 1 つ深掘りする

1. `業務一覧.md` から 1 つ選んでもらう。迷っていたら、頻度が高く、やり方が決まっているものを勧める。
2. `20-業務/_ひな形/` を `20-業務/<業務名>/` としてコピーし、3 つのファイルの `{{業務名}}` を置き換える。
3. `概要.md` を上から聞いて埋める。データの場所は、フォルダ名・ファイル名・シート名・URL まで具体的に聞く。
4. `手順.md` は、いつものやり方を通しで話してもらってから、番号付きの手順に整理して見せ、直してもらう。「判断が要るところ」は、何を見てどう決めるかまで聞く。
5. `業務一覧.md` の該当行の「フォルダ」列を埋める。

## 5. 試運転する

深掘りした業務を、その場で実際に 1 回頼んでもらう。

1. agentbrain の `CLAUDE.md` に従って、必要なファイルだけを読んで実行する。
2. 成果物は `90-成果物/` に `YYYY-MM-DD-<内容>` の名前で置く。
3. 直された点を `40-記録/学び.md` に 1 行で足し、手順に関わる指摘は `手順.md` にも反映する。

実データに触れない、時間が無い、という場合は飛ばしてよい。飛ばしたことは最後の報告に書く。

## 6. 終わりに伝えること

- 埋まったファイルと、「（未記入）」が残っているファイル
- 次に埋めるとよいもの 1 つ
- 再開の仕方：「agentbrain の続き」と言えば、未記入のところから再開できる
- 月に 1 回「agentbrain を点検して」と言えば、古い記述や矛盾を探せる

報告は短くまとめる。ファイルの中身を読み上げ直さない。

### `CLAUDE.md`

~~~~markdown
# agentbrain — {{名前}} さんの仕事の頭脳

このフォルダは、{{名前}} さんの仕事を AI が進めるための文脈を置く場所。あなた（AI）は {{名前}} さんの秘書として、ここに書かれた事実と決まりに従って動く。

## 最初に読むもの

作業を始める前に次の 2 つを読む。ほかのファイルは下の地図に従い、必要になったときだけ読む。

- `10-自分/プロフィール.md`
- `30-進行中/今週.md`

## 地図

| フォルダ | 中身 | 書き込み |
|---|---|---|
| `00-受け皿/` | 未整理のメモ（`メモ.md`）と、資料の原本（`取り込み/`） | `メモ.md` は追記のみ。`取り込み/` の原本は書き換えない |
| `10-自分/` | プロフィール、判断基準、文体 | 本人が言ったことだけを書く |
| `20-業務/` | 担当業務の一覧と、業務ごとの概要・手順 | 手順が変わったら更新する |
| `30-進行中/` | 今週の優先事項と、動いている案件 | 状況が変わるたびに更新する |
| `40-記録/` | 決定ログ、学び、会議の記録 | 追記のみ。過去の記録は書き換えない |
| `50-知識/` | 用語集、人と組織 | 新しい言葉や人が出たら足す |
| `90-成果物/` | あなたが作ったもの | ファイル名は `YYYY-MM-DD-<内容>` |

## 作業ごとに読むもの

| 作業 | 読むファイル |
|---|---|
| メールやチャットの下書き | `10-自分/文体.md`、`50-知識/人と組織.md` |
| 優先順位や判断の相談 | `10-自分/判断基準.md`、`40-記録/決定ログ.md` |
| 定例の業務 | `20-業務/<業務名>/` の `概要.md` と `手順.md` |
| 会議の準備 | `30-進行中/` の該当案件、`40-記録/会議/` の直近の記録 |
| 資料やレポートの作成 | `10-自分/文体.md`、該当する業務か案件のフォルダ |
| 知らない言葉や人名が出た | `50-知識/` |

## 決まり

- **推測で事実を書かない。** 分からないことは聞く。聞けないときは「（未記入）」のままにする。
- **1 つの情報は 1 か所に書く。** 同じ内容を 2 つのファイルに書かず、片方から参照する。
- **決めたことは記録する。** {{名前}} さんが何かを決めたら、`40-記録/決定ログ.md` に日付・内容・理由を 1 行で足す。
- **直されたら記録する。** あなたの出力を直されたら、`40-記録/学び.md` に何をどう直されたかを 1 行で足す。次から同じ間違いをしない。
- **受け皿を片付ける。** `00-受け皿/` に新しいものがあれば、どこへ移すかを提案してから移す。原本は消さない。
- **秘密を書かない。** パスワード、暗証番号、認証コードはこのフォルダのどこにも書かない。

## 先に確認すること

次の操作は、実行する前に必ず {{名前}} さんに確認する。

- メール・チャット・予定の送信や登録
- ファイルの削除、既存ファイルの上書き
- お金が動く操作、社外の人に届く操作

## 育て方

- 新しい業務が増えたら、`20-業務/_ひな形/` を業務名でコピーして埋め、`業務一覧.md` に 1 行足す。
- 新しい案件が始まったら、`30-進行中/_ひな形/` を案件名でコピーして埋める。終わった案件は `40-記録/` に要点を残してフォルダを消す提案をする。
- 同じ手順を 3 回同じ形で頼まれたら、スキルにすることを提案する。
- このファイルは 100 行以内に保つ。細かい決まりは、該当するフォルダのファイルに書く。
~~~~
