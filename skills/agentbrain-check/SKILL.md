# agentbrain を点検する

agentbrain は使うほど記録が増え、放っておくと古い記述と矛盾がたまる。点検は、それを見つけて直す提案をする作業。**見つけたことを先に報告し、承認されたものだけを直す。**

## 始める前に

作業フォルダに agentbrain があること（`CLAUDE.md` の見出しが `# agentbrain`）を確かめる。無ければ、agentbrain-setup で作ることを勧めて終える。

読むのは次の範囲。`90-成果物/` と `00-受け皿/取り込み/` の原本は、必要なものだけ開く。

- `CLAUDE.md`、`10-自分/`、`20-業務/`、`30-進行中/`、`40-記録/`（会議は直近 1 か月分）、`50-知識/`、`00-受け皿/メモ.md`

## 見るところ

### 1. 受け皿

- `00-受け皿/メモ.md` の各行について、移す先を決める：やること → `30-進行中/今週.md`、決めたこと → `40-記録/決定ログ.md`、言葉や人 → `50-知識/`、業務のやり方 → 該当する `手順.md`。
- `00-受け皿/取り込み/` に、まだどこにも反映されていない資料があれば、何を読み取ってどこへ書くかを挙げる。
- 移した行は `メモ.md` から消す。`取り込み/` の原本は消さない。

### 2. 未記入

- 「（未記入）」と `{{` が残っているファイルと箇所を数える。
- 全部を埋めようとしない。最近の仕事に関係するものから、次に埋める候補を 3 つまで選ぶ。

### 3. 古い記述

- `30-進行中/今週.md` の更新日が 7 日以上前。
- `30-進行中/<案件>/概要.md` の更新日が 30 日以上前、または締切を過ぎている。
- `20-業務/業務一覧.md` に行があるのにフォルダが無い、またはフォルダがあるのに行が無い。
- `50-知識/人と組織.md` の人が、直近の記録に一度も出てこない（異動や担当替えの可能性として聞く）。

### 4. 矛盾と重複

- `40-記録/決定ログ.md` の新しい決定と、`10-自分/判断基準.md` や `手順.md` の記述が食い違っている。
- 同じ内容が 2 つ以上のファイルに書かれている。
- `CLAUDE.md` の地図と、実際のフォルダ構成が合っていない。

### 5. 昇格

- `40-記録/学び.md` に同じ種類の指摘が 2 回以上ある → 全体に関わるなら `CLAUDE.md` の決まりへ、業務に限るならその業務の `手順.md` か `CLAUDE.md` へ移す。移した行には「反映済み」と書き足す。
- 同じ業務を、同じ手順で 3 回以上こなしている → スキルにすることを勧める。
- `CLAUDE.md` が 100 行を超えている → 細かい決まりを該当フォルダのファイルへ移す。

## 報告の形

次の順で、短く報告する。該当が無い項目は書かない。

1. 全体の状態を 1〜2 行（よく使われている箱、止まっている箱）
2. 直す提案を番号付きで。1 件 1 行で「どのファイルの、何を、どうするか」
3. 本人に聞きたいこと（判断がつかない矛盾、消してよいか分からないもの）

提案への返事を待ち、承認された番号だけを実行する。削除と上書きは、対象を示してから行う。実行後に、変えたファイルを 1 行ずつ伝える。
