agentbrain はじめ方へ

AI に、仕事を引き継ぐフォルダ。

役割、業務のやり方、今の状況、過去の決定。AI に頼むたびに説明し直していることを、1 つのフォルダに貯めます。Claude にコネクタを足すと、フォルダの作成からインタビューまで Claude が進めます。

    フォルダの中身を読み込んでいます。

    Claude があなたに聞く質問答えるまで「（未記入）」のまま。推測では埋めません

    はじめ方

    用意するのは、フォルダを選べる Claude（デスクトップアプリの Cowork か Claude Code）だけです。

    1. Claude にコネクタを足す

      設定のコネクタから「カスタムコネクタを追加」を開き、名前に agentbrain、URL に次を貼ります。

      https://agentbrain.taskf.co.jp/mcp

      Claude Code では claude mcp add --transport http agentbrain https://agentbrain.taskf.co.jp/mcp

    2. 置き場所を選んで、頼む

      agentbrain を置きたいフォルダを Claude の作業フォルダに選び、こう頼みます。名前を答えると、上のフォルダ一式がそこに置かれます。

      agentbrain を作って

    3. 質問に答える

      Claude がプロフィール、担当業務、今週の状況を順に聞きます。答えるたびにファイルへ書き込まれるので、途中でやめても残ります。最初の 1 回は 10〜15 分です。

      分からない質問は飛ばせます。手元に資料があれば、答える代わりに「取り込み」フォルダへ入れても構いません。

    4. 業務を 1 つ、任せてみる

      頻度が高く、やり方が決まっている業務を 1 つ選んで手順を話します。Claude が整理して書いたら、その場で実際に 1 回頼みます。直したところは記録され、次の仕事に生かされます。

    作ったあとは、4 つの頼み方で足ります

    agentbrain の続き
    未記入のところから、インタビューを再開します。
    業務を追加して
    業務を 1 つ選び、概要と手順を聞き取って書きます。
    受け皿を片付けて
    放り込んだメモと資料を、どの箱へ移すか提案してから移します。
    agentbrain を点検して
    古い記述、食い違い、繰り返し直されていることを探し、直す案を出します。月に 1 回が目安です。

    コネクタがすること、しないこと

    コネクタは手順書と雛形を Claude に渡すだけです。フォルダを読み書きするのは、あなたの手元の Claude です。

    Claude に返すもの

    • フォルダを作り、インタビューで埋める手順
    • 点検の手順
    • 雛形のファイル 16 点（上で見られるものと同じ）

    受け取らないもの

    • インタビューへの回答
    • フォルダに書かれた内容
    • 名前、メールアドレスなどの登録情報（登録そのものがありません）

    よくある質問

    どの Claude で使えますか

    作業フォルダを選べる環境で使えます。Claude デスクトップアプリの Cowork と、Claude Code です。フォルダを選べない通常のチャットでは、Claude がファイルを書けないため使えません。

    費用はかかりますか

    コネクタと雛形は無料です。Claude 自体の利用プランは別に必要です。

    全部の項目を埋めないと使えませんか

    いいえ。プロフィールと業務を 1 つ書けば使い始められます。残りは、仕事で使ううちに足りないところが分かるので、そこから足していきます。

    すでにあるマニュアルや議事録は使えますか

    使えます。「取り込み」フォルダに入れると、Claude が読み取った内容を「こう書いてよいですか」と確かめてから、該当する箱に書きます。原本は書き換えません。

    コネクタを外したら、フォルダは使えなくなりますか

    使えます。フォルダの先頭にある CLAUDE.md に、読む順番と育て方が書いてあるので、コネクタが無くても Claude はそのフォルダをもとに動きます。コネクタが要るのは、作るときと点検するときだけです。

    パスワードを書いても大丈夫ですか

    書かないでください。パスワードや認証コードはフォルダのどこにも書かない決まりにしてあり、聞かれて答えても Claude は書き込みません。
