# agentbrain

仕事の文脈を AI に渡すためのフォルダ「agentbrain」を作り、育てるためのプラグイン。

AI に仕事を頼むたびに背景を説明し直すのをやめ、自分の役割・業務のやり方・今の状況・過去の決定を 1 つのフォルダに貯めていく。AI はそのフォルダを読んで動く。

## できること

| 頼み方 | 起きること |
|---|---|
| 「agentbrain を作って」 | フォルダの雛形を置き、インタビューで中身を埋める |
| 「agentbrain の続き」 | 未記入のところから再開する |
| 「業務を追加して」 | 業務を 1 つ選び、概要と手順を聞き取って書く |
| 「agentbrain を点検して」 | 受け皿の片付け、古い記述や矛盾の発見、決まりへの昇格を提案する |

## フォルダの形

中身は 6 種類に分かれる。

| 箱 | フォルダ | 中身 |
|---|---|---|
| 地図 | `CLAUDE.md` | どこに何があるか、どう動くか |
| 事実 | `10-自分/` `50-知識/` | 本人・関係者・言葉についての本当のこと |
| 手順 | `20-業務/` | 担当業務の一覧と、業務ごとの概要・手順 |
| 今 | `30-進行中/` | 今週の優先事項と動いている案件 |
| 記録 | `40-記録/` | 決定ログ、学び、会議 |
| 受け皿と成果物 | `00-受け皿/` `90-成果物/` | 未整理のものと、AI が作ったもの |

雛形の実物は [`skills/agentbrain-setup/template/`](skills/agentbrain-setup/template/) にある。

## 入れ方

### Claude デスクトップアプリ

1. `agentbrain.plugin` を受け取る
2. カスタマイズ → プラグイン → プラグインをアップロード
3. agentbrain を置きたいフォルダを作業フォルダに選び、「agentbrain を作って」と頼む

### Claude Code

```
/plugin marketplace add bytask/agentbrain
/plugin install agentbrain@agentbrain
```

## 使い続けるコツ

- 思いついたことは `00-受け皿/メモ.md` に書くか、資料を `00-受け皿/取り込み/` に入れる。整理は AI に任せる
- AI の出力を直したら、そのまま伝える。`40-記録/学び.md` に残り、次から繰り返さない
- 全部を一度に埋めない。仕事で使ううちに足りないところが分かるので、そこから足す
- 月に 1 回、点検を頼む

## 配布物を作る

```
python3 scripts/build.py
```

`dist/agentbrain.plugin` ができる。
